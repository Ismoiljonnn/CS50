Programming Fundamentals (Scratch Building Blocks)
Functions: Actions, commands, or verbs that tell the computer to execute a specific operation. In Scratch, these are represented by puzzle blocks like say or move.

Arguments: Specific inputs passed into functions to modify, customize, or quantify their behavior. For instance, in the block move 10 steps, the integer 10 serves as the argument telling the move function how far to travel.

Side Effects: Observable external changes or visual/audible outcomes caused by executing a function. Playing an audio file, lighting up a pixel, or showing a speech bubble on screen are all side effects of underlying code executions.

Return Values: Data or results computed and handed back by a function to the rest of the program after execution. For example, a block asking for a user's name returns whatever string the user typed so other parts of the script can process it.

Variables: Labeled storage containers in computer memory designed to hold values (such as integers, text, or boolean states) that can change over time during program execution—such as tracking a player's score, timer, or health.

Advanced Concepts Introduced in Scratch
Events: Triggers or asynchronous signals that kick off the execution of a specific block of code. Examples include clicking the green flag button (when green flag clicked) or pressing a keyboard key.

Parallelism: The simultaneous execution of multiple independent sequences of code or threads. In Scratch, having two distinct stacks of blocks trigger under different events—or even the same event—allows multiple tasks to run at the same time.

Abstraction: The practice of hiding complex implementation details behind a simpler interface. In Scratch, creating custom "Make a Block" functions allows developers to bundle many repetitive steps under a single named block, making the overall codebase cleaner, modular, and easier to maintain.

Threads & Bugs:

Thread: An individual, independent sequence of instructions running concurrently with other tasks in memory.

Bug: An unintended flaw, mistake, or logical error in source code that leads to unexpected results, program crashes, or incorrect output.

Race Condition: A specific type of concurrency bug where two or more parallel threads attempt to read or modify a shared state or variable at the same time, leading to unpredictable timing-dependent errors.

Scratch serves as a bridge between human reasoning and actual software architecture. By visualizing core programming fundamentals—such as functions, variables, control flow, events, abstraction, and multi-threading—developers build an intuitive foundation for how code operates under the hood before transitioning to text-based languages like C or Python.
